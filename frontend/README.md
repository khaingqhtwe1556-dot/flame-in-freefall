# FLAMEGUARD SI frontend

The React/TypeScript application is a source-attributed demo built from reviewed NASA PSI metadata. Its investigation catalog does not include downloaded or parsed raw experiment files.

From this directory:

```bash
corepack pnpm install
corepack pnpm dev
```

Quality checks:

```bash
corepack pnpm lint
corepack pnpm test
corepack pnpm build
```

See the project-level `../README.md` and `../Data resources.md` for setup, source inventory, ranking caveats, and the later-phase roadmap.
